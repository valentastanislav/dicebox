# DICEBOX – parallel version

OpenMP parallel version of DICEBOX for capture on isolated resonances
(energy-, spin- and parity-well defined initial state).

The code is based on the original code and uses the algorithm of
František Bečvář.

The serial version of DICEBOX is distributed separately by the
IAEA Nuclear Data Section under the GNU GPL:
https://www-nds.iaea.org/dicebox/
